# At-Turath Academy — ম্যানেজমেন্ট সিস্টেম

At-Turath Academy একটা অনলাইন একাডেমি, যেখানে **ব্যাচ** আর **ওয়ান-টু-ওয়ান** দুই ধরনের স্টুডেন্টই পড়ে। এই সিস্টেম দিয়ে একাডেমির সব কাজ এক জায়গায় করা যায়। এটা বাংলা ভাষার একটা ওয়েব অ্যাপ।
- অ্যাপটা চলে GitHub Pages থেকে, আর ডেটা থাকে Google-এর Firebase-এ। দুটোই ফ্রি।
- লগইন করতে হয় Google (Gmail) অ্যাকাউন্ট দিয়ে।
- মোবাইল আর কম্পিউটার দুটোতেই চলে।

## একবারের সেটআপ

### ১. Firebase প্রজেক্ট
1. https://console.firebase.google.com এ মালিকের Gmail দিয়ে ঢুকে একটা প্রজেক্ট খুলুন (Analytics বা Gemini বন্ধ রাখুন)।
2. **Build → Authentication → Get started → Sign-in method → Google → Enable → Save।** একই পেজে **Settings → Authorized domains**-এ `mhsiddiqui96.github.io` যোগ করুন।
3. **Build → Firestore Database → Create database** → Location **asia-south1 (Mumbai)** → **production mode** → Create।
4. ⚙️ **Project settings → Your apps → `</>`** দিয়ে একটা Web app বানান, আর `firebaseConfig` অংশটা `js/config.js`-এ বসান। সঙ্গে মালিকের Gmail-টাও বসান।

### ২. ডেটাবেসের নিয়ম বসানো
1. Firebase Console → **Firestore Database → Rules** ট্যাবে যান।
2. সেখানে আগে থেকে যা লেখা আছে, সব মুছে দিন।
3. এই রিপোজিটরির `firestore.rules` ফাইলের পুরো লেখাটা কপি করে বসান। দেখে নিন, `function owner()`-এর ভেতরে মালিকের Gmail আছে কিনা।
4. **Publish** চাপুন।

### ৩. অ্যাপ চালু
GitHub রিপোজিটরির **Settings → Pages**-এ Branch হিসেবে `main` আর ফোল্ডার `/ (root)` বাছাই করুন। অ্যাপের লিংক:
**https://mhsiddiqui96.github.io/Academy-management-system/**

মোবাইলে লিংকটা খুলে ব্রাউজারের মেনু থেকে **Add to Home screen** চাপলে লোগোসহ অ্যাপের আইকন পাবেন।

### ৪. প্রথম লগইন ও আগের ডেটা
1. মালিকের Gmail দিয়ে লগইন করুন।
2. এই ব্রাউজারে আগের (লোকাল মোডের) ডেটা থাকলে ড্যাশবোর্ড বা সেটিংসে **"আগের ডেটা অনলাইনে তুলুন"** বাটন আসবে। একবার চাপলেই সব ডেটা অনলাইনে উঠে যাবে।
3. অন্য কোনো ব্রাউজারে বা ব্যাকআপ ফাইলে ডেটা থাকলে **সেটিংস → ব্যাকআপ থেকে ফেরত আনুন** দিয়ে ফাইলটা দিন।

### ৫. অ্যাডমিন বা শিক্ষককে অনুমতি দেওয়া
1. **সেটিংস → লগইনের অনুমতি → + অনুমতি দিন**-এ যান।
2. যাকে অনুমতি দেবেন, তার Gmail আর ভূমিকা দিন। শিক্ষক হলে কোন শিক্ষক, সেটাও বাছাই করুন।
3. এরপর তিনি অ্যাপের লিংক খুলে সেই Gmail দিয়ে লগইন করলেই ঢুকতে পারবেন।

## ব্যবহারের নিয়ম

- তথ্য যোগ করার ক্রম: **শিক্ষক → ব্যাচ → স্টুডেন্ট।** ওয়ান-টু-ওয়ান স্টুডেন্টের জন্য ব্যাচ লাগে না।
- **আপনি নিজে পড়ালে:** নিজেকে শিক্ষক হিসেবে যোগ করে "ধরন"-এ **আমি নিজে (মালিক) — সম্মানী নেই** বাছাই করুন। তাহলে আপনার ক্লাসের পুরো ফি একাডেমির আয়ে থাকবে, কোনো শিক্ষকের পাওনা তৈরি হবে না। রুটিন আর এসাইনমেন্ট আগের মতোই চলবে।
- **শিক্ষকের অংশ:** নিয়ম বসাতে হয় ব্যাচে, অথবা ওয়ান-টু-ওয়ান স্টুডেন্টে। নিয়ম দুই রকম: ফি-এর শতাংশ, বা প্রতি স্টুডেন্ট মাসে নির্দিষ্ট টাকা। স্টুডেন্ট ফি দিলে তবেই শিক্ষকের অংশ পাওনায় যোগ হয়।
- **স্টাফের কমিশন:** স্টাফের প্রোফাইলে কমিশনের ডিফল্ট নিয়ম থাকে। নতুন স্টুডেন্ট যোগ করার সময় "ভর্তি করিয়েছেন" ঘরে স্টাফ বাছাই করলে, তখনকার নিয়ম ওই স্টুডেন্টের সাথে সেভ হয়। কোনো ভর্তিতে ব্যতিক্রম হলে মালিক শুধু ওই স্টুডেন্টের কমিশন বদলাতে পারেন। কমিশন পাওনা হয় স্টুডেন্টের **প্রথম ফি আসার দিন।**
- অ্যাডমিন ফি নিলে বা নতুন ভর্তি করালে, শিক্ষকের অংশ আর কমিশন হিসাব হয় **মালিক অ্যাপ খুললে।** শিক্ষকের নিজের হিসাবও তখনই হালনাগাদ হয়।
- শিক্ষক বা স্টাফকে টাকা দেবেন শুধু "শিক্ষকের হিসাব" বা "স্টাফ" পেজ থেকে। তাহলে খরচ নিজে থেকে যোগ হবে, আর বাকির হিসাব ঠিক থাকবে।
- উপরের ডান কোণের চিহ্ন: **☁️ সেভ আছে** / **⏳ সেভ হচ্ছে** / **📴 অফলাইন**। অফলাইনে করা কাজ ইন্টারনেট ফিরলে নিজে থেকেই সেভ হয়।
- মাসে একবার **সেটিংস → ব্যাকআপ ডাউনলোড** করে ফাইলটা Google Drive-এ রেখে দেওয়া ভালো।

## টেকনিক্যাল তথ্য (ডেভেলপারদের জন্য)

- HTML, CSS আর ভ্যানিলা JavaScript (ES module) দিয়ে লেখা, কোনো build step নেই। Firebase SDK (10.14.1) `js/vendor/firebase.js`-এ বান্ডেল করা আছে।
- `js/config.js`-এ `FIREBASE_CONFIG` খালি (`null`) থাকলে অ্যাপ **লোকাল মোডে** চলে। তখন ডেটা থাকে `localStorage`-এ, একজন ব্যবহারকারীর জন্য, ডেমো ডেটাসহ।
- লোকালি চালাতে: `python3 -m http.server` চালিয়ে `http://localhost:8000` খুলুন।
- পরীক্ষা (`tests/`):
  - `cd tests && npm install && npm run test:rules` চালালে ডেটাবেসের নিয়মের ৫৪টা পরীক্ষা হয় (Firebase এমুলেটরে, Java লাগে)।
  - `tests/e2e.cjs` পুরো লগইন ব্যবস্থা পরীক্ষা করে।
  - অ্যাপ `?emulator&owner=<email>` দিয়ে খুললে নকল Firebase-এ চলে।
