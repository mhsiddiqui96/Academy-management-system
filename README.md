# At-Turath Academy — ম্যানেজমেন্ট সিস্টেম

At-Turath Academy অনলাইন একাডেমি। এতে **ব্যাচে পড়া** আর **ওয়ান-টু-ওয়ান** দুই ধরনের স্টুডেন্টই আছে। এই সিস্টেম একাডেমির সব কাজ এক জায়গায় করার জন্য একটা সহজ, বাংলা ভাষার ওয়েব অ্যাপ।
এর জন্য কোনো সার্ভার বা মাসিক খরচ লাগে না। GitHub Pages-এ ফ্রিতে চলে, আর মোবাইল ও কম্পিউটার দুটোতেই ব্যবহার করা যায়।

## অনলাইনে চালু করবেন যেভাবে (একবারই করতে হবে)

1. GitHub-এ এই রিপোজিটরির **Settings** ট্যাবে যান।
2. বাঁ দিকের মেনু থেকে **Pages**-এ ক্লিক করুন।
3. **Source**-এ "Deploy from a branch" বাছাই করুন।
4. **Branch**-এ `main` আর ফোল্ডারে `/ (root)` বাছাই করে **Save** চাপুন।
5. ১-২ মিনিট পর ওই পেজের উপরের দিকে আপনার লিংক দেখাবে:
   `https://mhsiddiqui96.github.io/Academy-management-system/`

লিংকটা মোবাইলের ব্রাউজারে খুলে মেনু থেকে **"Add to Home screen"** চাপলে অ্যাপের মতো আইকন পাবেন।

> ⚠️ রিপোজিটরি **Private** হলে ফ্রি অ্যাকাউন্টে GitHub Pages চলে না। তখন রিপোজিটরিটা Public করতে হবে,
> নয়তো GitHub Pro নিতে হবে। Public করলেও আপনার স্টুডেন্টদের কোনো ডেটা কেউ দেখতে পাবে না, কারণ
> ডেটা GitHub-এ যায় না, শুধু আপনার ব্রাউজারে থাকে। শুধু অ্যাপের কোডটা পাবলিক থাকবে।

## প্রথমবার ব্যবহার

1. **সেটিংস**-এ গিয়ে একাডেমির নাম আর ফোন নম্বর দিন।
2. এই ক্রমে তথ্য যোগ করুন: **শিক্ষক → ব্যাচ (শিক্ষক এসাইন করে) → স্টুডেন্ট**।
   - ব্যাচের স্টুডেন্ট: "পড়ার ধরন"-এ **ব্যাচে পড়ে** দিয়ে ব্যাচ বাছাই করুন।
   - ওয়ান-টু-ওয়ান স্টুডেন্ট: **ওয়ান-টু-ওয়ান** দিয়ে শিক্ষক, কোর্স, সময়, ক্লাস লিংক আর ফি লিখুন।
   - বিদেশে থাকা স্টুডেন্টের নম্বর **+দেশের কোডসহ** লিখুন (যেমন +447700900123), তাহলে WhatsApp রিমাইন্ডার ঠিক নম্বরে যাবে।
3. প্রতি মাসে **ফি ও রিমাইন্ডার** পেজে কে দিয়েছে আর কে দেয়নি দেখুন, আর বাকিদের WhatsApp বাটনে চাপ দিন। বিদেশ থেকে আসা ফি যত টাকা হাতে এসেছে সেই অঙ্কে লিখুন।
4. খরচ হলে **আয়-ব্যয়** পেজে "ব্যয় যোগ" করুন।
5. পরীক্ষা নিলে **প্রগ্রেস** পেজে নম্বর তুলে রাখুন।

শুধু দেখে বুঝতে চাইলে সেটিংস থেকে **"ডেমো ডেটা লোড করুন"** চাপুন। পরে "সব ডেটা মুছে ফেলুন" দিয়ে খালি করে নিজের ডেটা দেওয়া শুরু করবেন।

## ☁️ অনলাইন ব্যাকআপ চালু করা (অবশ্যই করবেন, একবারই করতে হবে)

এটা চালু করলে প্রতিটা পরিবর্তন নিজে থেকে আপনার GitHub-এর একটা **Private** রিপোজিটরিতে সেভ হবে, যেটা শুধু আপনি দেখতে পাবেন।
ফোন বা ল্যাপটপ নষ্ট বা হারিয়ে গেলেও ডেটা হারাবে না। প্রতিটা সেভের পুরোনো ভার্সনও থেকে যায়, তাই ভুল করে কিছু মুছে ফেললেও ফেরত আনা যায়।

**ধাপ ১: ডেটার জন্য Private রিপোজিটরি বানান**
1. https://github.com/new এ যান।
2. **Repository name**-এ লিখুন `at-turath-data`
3. **Private** বাছাই করুন (খুব জরুরি)।
4. **Create repository** চাপুন।

**ধাপ ২: টোকেন বানান (এটা অ্যাপকে ওই রিপোজিটরিতে সেভ করার অনুমতি দেয়)**
1. https://github.com/settings/personal-access-tokens/new এ যান।
2. **Token name**: `At-Turath App`
3. **Expiration**: সবচেয়ে লম্বা মেয়াদটা বাছাই করুন। মেয়াদ শেষ হলে অ্যাপের উপরে ❌ দেখাবে, তখন এভাবেই নতুন টোকেন বানিয়ে দেবেন।
4. **Repository access**: **Only select repositories** → `at-turath-data` বাছাই করুন।
5. **Permissions** → **Repository permissions** → **Contents**: **Read and write** দিন।
6. নিচে **Generate token** চাপুন, তারপর `github_pat_...` দিয়ে শুরু হওয়া লেখাটা কপি করুন।

**ধাপ ৩: অ্যাপে চালু করুন**
1. অ্যাপের **সেটিংস** → **অনলাইন ব্যাকআপ**-এ যান।
2. রিপোজিটরির ঘরে `mhsiddiqui96/at-turath-data` আগে থেকেই লেখা আছে। টোকেনের ঘরে কপি করা টোকেনটা দিন।
3. **চালু করুন** চাপুন। উপরের ডান কোণে **☁️ অনলাইনে সেভ আছে** দেখালে কাজ শেষ।

**নতুন ফোন বা কম্পিউটারে:** অ্যাপের লিংক খুলে ধাপ ৩ আবার করুন। সব ডেটা চলে আসবে।
টোকেনটা কোথাও লিখে রাখার দরকার নেই, হারালে ধাপ ২ আবার করে নতুন টোকেন বানাবেন।

উপরের ডান কোণের চিহ্নগুলোর মানে:

| চিহ্ন | মানে |
|---|---|
| ☁️ অনলাইনে সেভ আছে | সব ঠিক আছে |
| ⏳ সেভ হচ্ছে… | এইমাত্র করা পরিবর্তন সেভ হচ্ছে |
| 📴 ইন্টারনেট নেই | কাজ চালিয়ে যান; ইন্টারনেট ফিরলে নিজে থেকেই সেভ হবে |
| ❌ অনলাইনে সেভ হয়নি | চিহ্নে চাপ দিয়ে সেটিংসে কারণ দেখুন (সাধারণত টোকেনের মেয়াদ শেষ) |
| ⚠️ অনলাইন ব্যাকআপ বন্ধ | ডেটা শুধু এই ডিভাইসে আছে, তাই উপরের ধাপগুলো করুন |

**পুরোনো ভার্সন ফেরত আনতে:** সেটিংস → "🕘 পুরোনো ভার্সনগুলো দেখুন"-এ প্রতিটা সেভের তালিকা আছে। কোনো নির্দিষ্ট দিনের ডেটা দরকার হলে Claude-কে বললেই ফেরত এনে দেবে।

**নিরাপত্তা:** টোকেনটা শুধু আপনার ডিভাইসের ব্রাউজারে থাকে। এটা দিয়ে কেবল `at-turath-data` রিপোজিটরিতেই কাজ করা যায়, আপনার অন্য কিছুতে নয়। কোনো ডিভাইস হারালে https://github.com/settings/personal-access-tokens থেকে টোকেনটা মুছে (Delete) দিন।

## টেকনিক্যাল তথ্য (ডেভেলপারদের জন্য)

- শুধু HTML, CSS আর ভ্যানিলা JavaScript ব্যবহার করা হয়েছে; কোনো build step নেই। `index.html` সরাসরি খুললেই চলে।
- লোকালি চালাতে: `python3 -m http.server` চালিয়ে `http://localhost:8000` খুলুন।
- ডেটা `localStorage`-এর `academy-ms-v1` key-তে JSON হিসেবে থাকে। অনলাইন ব্যাকআপ চালু থাকলে প্রতিটা পরিবর্তনের পর GitHub Contents API দিয়ে ডেটা রিপোজিটরির `academy-data.json` ফাইলে কমিট হয় (`sha` দিয়ে দুই ডিভাইসের সংঘাত ধরা হয়)।
- ফাইল: `index.html` (লেআউট), `css/style.css` (ডিজাইন), `js/app.js` (সব লজিক)।
