# একাডেমি ম্যানেজমেন্ট সিস্টেম

কোচিং সেন্টার বা একাডেমির সব কাজ এক জায়গায় করার জন্য একটা সহজ, বাংলা ভাষার ওয়েব অ্যাপ।
এর জন্য কোনো সার্ভার বা মাসিক খরচ লাগে না। GitHub Pages-এ ফ্রিতে চলে, আর মোবাইল ও কম্পিউটার দুটোতেই ব্যবহার করা যায়।

## অনলাইনে চালু করবেন যেভাবে (একবারই করতে হবে)

1. GitHub-এ এই রিপোজিটরির **Settings** ট্যাবে যান।
2. বাঁ দিকের মেনু থেকে **Pages**-এ ক্লিক করুন।
3. **Source**-এ "Deploy from a branch" বাছাই করুন।
4. **Branch**-এ `main` আর ফোল্ডারে `/ (root)` বাছাই করে **Save** চাপুন।
5. ১-২ মিনিট পর ওই পেজের উপরের দিকে আপনার লিংক দেখাবে:
   `https://mhsiddiqui96.github.io/Academy-management-system/`

লিংকটা মোবাইলের ব্রাউজারে খুলে মেনু থেকে **"Add to Home screen"** চাপলে অ্যাপের মতো আইকন পাবেন।

> ⚠️ রিপোজিটরি **Private** হলে ফ্রি অ্যাকাউন্টে GitHub Pages চলে না। তখন রিপোজিটরিটা Public করতে হবে,
> নয়তো GitHub Pro নিতে হবে। Public করলেও আপনার স্টুডেন্টদের কোনো ডেটা কেউ দেখতে পাবে না, কারণ
> ডেটা GitHub-এ যায় না, শুধু আপনার ব্রাউজারে থাকে। শুধু অ্যাপের কোডটা পাবলিক থাকবে।

## প্রথমবার ব্যবহার

1. **সেটিংস**-এ গিয়ে একাডেমির নাম আর ফোন নম্বর দিন।
2. এই ক্রমে তথ্য যোগ করুন: **শিক্ষক → ব্যাচ (শিক্ষক এসাইন করে) → স্টুডেন্ট (ব্যাচ বাছাই করে)**।
3. প্রতি মাসে **বেতন ও রিমাইন্ডার** পেজে কে দিয়েছে আর কে দেয়নি দেখুন, আর বাকিদের WhatsApp বাটনে চাপ দিন।
4. খরচ হলে **আয়-ব্যয়** পেজে "ব্যয় যোগ" করুন।
5. পরীক্ষা নিলে **প্রগ্রেস** পেজে নম্বর তুলে রাখুন।

শুধু দেখে বুঝতে চাইলে সেটিংস থেকে **"ডেমো ডেটা লোড করুন"** চাপুন। পরে "সব ডেটা মুছে ফেলুন" দিয়ে খালি করে নিজের ডেটা দেওয়া শুরু করবেন।

## ⚠️ ডেটা ও ব্যাকআপ (অবশ্যই পড়ুন)

- এই ভার্সনে সব ডেটা **যে ব্রাউজারে কাজ করছেন সেই ব্রাউজারেই** জমা থাকে। ইন্টারনেট না থাকলেও খোলা পেজে কাজ চলে।
- ব্রাউজারের "Clear data/history" করলে বা ফোন বদলালে ডেটা হারিয়ে যেতে পারে।
- তাই **প্রতি সপ্তাহে সেটিংস → "ব্যাকআপ ডাউনলোড"** করে ফাইলটা Google Drive-এ রেখে দিন।
- অন্য ডিভাইসে একই ডেটা দরকার হলে ব্যাকআপ ফাইলটা সেখানে "ব্যাকআপ থেকে ফেরত আনুন" দিয়ে লোড করুন।
- একাধিক শিক্ষক যার যার ফোন থেকে একসাথে লাইভ ডেটায় কাজ করতে চাইলে ফেজ-২ (অনলাইন ডেটাবেস ও লগইন) লাগবে। বিস্তারিত ডিজাইন ডকুমেন্টে আছে।

## টেকনিক্যাল তথ্য (ডেভেলপারদের জন্য)

- শুধু HTML, CSS আর ভ্যানিলা JavaScript ব্যবহার করা হয়েছে; কোনো build step নেই। `index.html` সরাসরি খুললেই চলে।
- লোকালি চালাতে: `python3 -m http.server` চালিয়ে `http://localhost:8000` খুলুন।
- ডেটা `localStorage`-এর `academy-ms-v1` key-তে JSON হিসেবে থাকে।
- ফাইল: `index.html` (লেআউট), `css/style.css` (ডিজাইন), `js/app.js` (সব লজিক)।
